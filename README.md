# 谷谷网申助手

独立 Chrome / Edge Manifest V3 扩展。网站负责用户资料，插件负责把缓存简历填写到招聘页面。当前开发版本 **0.3.11**。

## 使用

1. 在谷谷网站的“网申资料”上传简历并一键写入，或手工编辑，修改自动同步。
2. 在招聘页面打开“谷”按钮；未登录时点击登录，完成后显示个人简历。
3. 可以直接在资料框修改字段，仅对本页生效，不回写网站。点击“开始填写”，逐项扫描、从修改后的缓存副本取值并填写。填写后检查页面，最终提交由用户完成。
4. 修改了网站资料后，在右上角“···”菜单刷新资料（会清除本页临时修改）；撤销、调试日志和退出也在此菜单。

面板不再显示可填数量、置信度和逐项勾选；打开只读取登录/资料缓存，滚动不会触发扫描。填写过程没有逐字段或逐轮服务器请求。缺少资料、不支持的控件和无法确认的结果不冒充成功。

## 本地安装与更新

Node.js 22+：

```bash
npm ci
npm run check
```

在 Edge/Chrome 扩展管理页开启开发者模式，加载本仓库 `dist/`。更新时重建同一路径，点击“重新加载”并刷新招聘标签，无需重新导入。构建产物不提交 Git。

CI 对分支和 PR 执行类型检查、构建及契约测试；当前没有浏览器商店或自动 Release 工作流。主应用发布与本地扩展重新加载是两件事。

## 0.3.11 改动

- 简历加一个开始按钮，运行中可停止；删除空闲滚动/输入/布局重扫。
- DOM 顺序执行，在访问每个控件时决定取值，不先构建待勾选匹配清单。
- 教育学院字段、实习/工作独立记录和顺序重复经历；旧项目细分信息合为描述。
- 修复缓存二次解析导致再次打开资料变空；会话恢复无需再次请求服务器。
- 未登录为紧凑登录卡；登录后展示可编辑资料与开始按钮，本页修改优先用于填写，不污染服务器缓存或其他标签页。
- 登录凭据在扩展私有 local 存储中保留至服务端有效期，刷新、扩展重载和重启不用重复扫码；旧 session 凭据自动迁移。资料仍为会话缓存，重启后首次读取请求一次。
- 普通控件先聚焦再赋值，以真实失焦触发 focusout，并两次延迟核对，处理受控输入恢复旧值或未提交编辑的问题。
- 调试报告保留脱敏字段类别与处理结果，放入更多菜单。

## 数据与权限

服务器 `GET /api/autofill/profile/snapshot`（主应用 0.3.53+）是个人资料基础来源；用户在插件的临时编辑覆盖本页值，不回写服务器。后台校验协议后在 `chrome.storage.session` 缓存，内容脚本拿不到 token。凭据存放在限制为 `TRUSTED_CONTEXTS` 的 `chrome.storage.local`，不使用网页 localStorage 或同步存储；服务端仍负责认证。登录、缓存缺失或手动刷新才请求服务器；旧 plan/validate 消息仅为兼容保留，新执行链不调用。

已知招聘域名的窄域内容脚本仅自动显示入口。未知企业自建站使用工具栏点击产生的 `activeTab` 权限，不申请全站常驻访问。`scripting` 用于主动注入，`storage` 用于短期会话与有界诊断，第一方 host 权限用于 `gudaya.chat` 登录/资料请求。

退出、过期、401 清除登录和缓存，切换账号通知所有面板取消运行并清空本页修改；浏览器会话结束只清除资料缓存。最近 80 条/24 小时诊断只保留固定计数；用户点击“复制调试信息”才生成最多 80 行结构报告，不含原始 DOM、选择器、字段文字、填写值、URL、简历或凭据，不上传服务器。

## 当前边界

- 不自动提交、不勾协议、不处理验证码、密码、证件、支付或附件。
- 普通文本写入后核对，失败尝试恢复空白/原值；核对只证明即时值保留，不证明网站已经保存。
- 原生选择控件仅填写空项；标准自定义下拉仅点击可归属的唯一精确选项。复杂级联/日期弹层、跨域 iframe、封闭 Shadow DOM 仍可能跳过。
- 按页面现有记录顺序对应缓存经历，不主动点击“添加经历”。用户应检查经历顺序与页面内容。
- 撤销只针对成功的普通/原生控件；自定义下拉不保证撤销。
- 合成 DOM 与后台消息测试不能替代真实 ATS 测试；0.3.11 的真实北森页面仍由用户重载后复核。

实现边界见[产品与执行架构](docs/product-and-architecture.md)。
